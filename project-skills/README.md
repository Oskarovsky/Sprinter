# Project-Specific AI Skills

This directory contains a set of AI-powered skills tailored for our project's development workflow. These skills are designed to assist developers in various stages of the development process, from planning to implementation and testing.

## What are Skills?

Skills are pre-defined prompts and instructions that guide the AI assistant to perform specific tasks. They help in automating repetitive tasks and ensuring consistency in our development process.

## How to use them?

To use a skill, you can invoke it by its name in the chat with the AI assistant. For example, to start a new sprint, you can type `sprint-init`.

## Available Skills

Here is a list of the available skills and their descriptions:

*   **sprint-init**: Initializes the project for a new sprint. It helps in setting up the sprint plan and goals.
*   **sprint-feature**: Helps in defining a new feature. It guides you through the process of creating a feature document.
*   **sprint-plan**: Creates a detailed implementation plan for a feature. It breaks down the feature into smaller, manageable tasks.
*   **sprint-implement**: Implements a feature based on the plan. It uses the AI's coding capabilities to modify the codebase.
*   **sprint-test**: Creates and runs tests for a feature. It helps in ensuring the quality of the implemented feature.
*   **sprint-commit**: Commits the changes for a feature. It helps in creating a well-formatted commit message.

These skills are a starting point and can be customized to fit our needs. You can modify the `SKILL.md` and `PROMPT.md` files in each skill's directory to change their behavior.
